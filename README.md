- Integrações com serviços externos;
- Automação comercial;
- Plataformas SaaS e arquitetura multi-tenant;

> **Objetivo:** transformar processos empresariais em sistemas digitais modernos, organizados, seguros e eficientes.

## 🏗️ Ecossistema PayTech e Projetos Técnicos

### 🛒 [PDV Backend — PayTech](https://github.com/Andreoliver998/pdv_backend)

Sistema de Ponto de Venda completo com **backend Node.js/Express**, **Prisma**, **PostgreSQL**, painel web administrativo, app Android nativo e arquitetura multi-tenant escalável.

Principais recursos:

- Autenticação com JWT;
- Gestão de terminais PDV;
- Pareamento por código;
- Sessões de operadores por terminal com PIN;
- Fluxo de vendas e pagamentos;
- Payment Intents;
- Painel web administrativo;
- App Android nativo em Kotlin;
- CORS configurável por ambiente;
- Deploy com Docker ou PM2;
- Suporte a ambiente de produção com HTTPS.

> **Stack:** Node.js, Express, Prisma, PostgreSQL, Docker, Kotlin, JWT.

---

### 🖥️ [PayTech Operating System](https://github.com/Andreoliver998/PayTech-Operating-System)

Plataforma full-stack criada para suportar a operação da PayTech, combinando frontend estático com backend em **Node.js + Express**, autenticação JWT, área administrativa protegida e suporte a uma arquitetura multi-tenant escalável.

Principais recursos:

- Login e criação de conta;
- Autenticação com JWT;
- Senhas com hash bcrypt;
- Cookie HttpOnly;
- Dashboard protegido por token;
- Rotas RESTful;
- Estrutura preparada para evolução SaaS.

> **Stack:** HTML5, JavaScript, Node.js, Express, JWT.

---

### 🤖 [PayTech AI Assistant](https://github.com/Andreoliver998/paytech-ai-assistant)

Plataforma proprietária de inteligência artificial conversacional com **streaming de respostas**, leitura inteligente de documentos com **RAG**, memória de sessões e backend escalável com **FastAPI**.

Principais recursos:

- Chat com streaming em tempo real via SSE;
- Upload e busca inteligente em documentos PDF, CSV e XLSX;
- RAG — Retrieval-Augmented Generation;
- Memória de sessões persistida em SQLite;
- Backend FastAPI com Swagger UI;
- Frontend estático com HTML, CSS e JavaScript;
- Modo debug para testes sem LLM;
- Configuração por variáveis de ambiente.

> **Stack:** Python, FastAPI, OpenAI, SQLite, JavaScript.
