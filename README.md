Sou **Carlos André Almeida de Oliveira**, desenvolvedor em formação contínua, estudante de **Engenharia de Software** e **Licenciatura em Matemática**, com foco em desenvolvimento Full Stack, arquitetura de sistemas, banco de dados, análise de dados, automação de processos e inteligência artificial aplicada.

Tenho base sólida em lógica matemática, raciocínio analítico e resolução de problemas, buscando escrever código organizado, seguro, escalável e eficiente.

  ## 💼 PayTech — Projeto Principal

  <div align="center">

    > A **PayTech** é uma iniciativa de tecnologia criada para desenvolver soluções digitais modernas para empresas, comércio, finanças e gestão operacional.

    </div>

    O ecossistema PayTech envolve sistemas de PDV, controle de vendas e estoque, painéis administrativos, gestão de produtos, clientes, operadores e terminais, aplicações web e mobile, APIs REST, banco de dados, integrações com serviços externos, automação comercial, plataformas SaaS e arquitetura multi-tenant.

    **Objetivo:** transformar processos empresariais em sistemas digitais modernos, organizados, seguros e eficientes.

    ---

    ## 🏗️ Projetos em Destaque

    ### 🛒 PDV Backend — PayTech
    > **Stack:** Node.js · Express · Prisma · PostgreSQL · Docker · Kotlin · JWT

    Sistema de Ponto de Venda completo com backend Node.js/Express, Prisma e PostgreSQL. Inclui gestão de terminais com pareamento por código, sessões de operadores por PIN, fluxo de vendas e Payment Intents, painel web administrativo, app Android nativo em Kotlin e deploy com Docker ou PM2.

    [![Repo](https://img.shields.io/badge/Ver%20Repositório-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Andreoliver998/pdv_backend)

    ---

    ### 🖥️ PayTech Operating System
    > **Stack:** HTML5 · JavaScript · Node.js · Express · JWT · bcrypt

    Plataforma full-stack para a operação central da PayTech. Combina frontend estático com backend Node.js/Express, autenticação JWT com refresh via cookie HttpOnly, senhas em bcrypt, dashboard protegido e arquitetura preparada para evolução SaaS multi-tenant.

    [![Repo](https://img.shields.io/badge/Ver%20Repositório-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Andreoliver998/PayTech-Operating-System)

    ---

    ### 🤖 PayTech AI Assistant
    > **Stack:** Python · FastAPI · OpenAI · SQLite · JavaScript · SSE

    Plataforma de IA conversacional proprietária com streaming de respostas em tempo real via SSE, leitura inteligente de documentos com RAG (PDF, CSV, XLSX), memória de sessões em SQLite e backend escalável com FastAPI. Frontend estático puro, sem dependências de framework.

    [![Repo](https://img.shields.io/badge/Ver%20Repositório-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Andreoliver998/paytech-ai-assistant)

    ---

    ### 🤟 Instituto Elo Libras — Sistema de Inscrição
    > **Stack:** Python · FastAPI · SQLAlchemy · PostgreSQL · Jinja2 · Mercado Pago

    Sistema completo de inscrição de alunos com pagamento via Mercado Pago, cadastro guiado, painel administrativo protegido por sessão, exportação CSV, logs e deploy pronto para produção no Render ou VPS.

    [![Repo](https://img.shields.io/badge/Ver%20Repositório-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Andreoliver998/instituto-elo-libras-sistema)

    ---

    ### 🗂️ CRM Pessoal — Sistema Web Clientes
    > **Stack:** Python · Streamlit · Google Sheets API · Plotly

    Sistema web para gestão de clientes com cadastro, edição, exclusão e busca integrados ao Google Sheets. Dashboard analítico com Plotly, multi-página com Streamlit e deploy via Docker, Render ou Streamlit Community Cloud.

    [![Repo](https://img.shields.io/badge/Ver%20Repositório-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Andreoliver998/sistema-web-clientes)
